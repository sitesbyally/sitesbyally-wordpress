# Build Setup with WordPress Studio

1. Open WordPress Studio and start the local server.

2. Navigate to theme folder.

   `cd wp-content/themes/sitesbyally`

3. Install dependencies.

   `npm install`

4. Compile, and minify SCSS and JS, auto-prefix CSS, and watch for changes.

   `npm run build -- --watch`

5. View site in browser using link from WordPress Studio (ex: sba.wp.local).
